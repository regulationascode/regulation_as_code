# Security policy

This public preview runs locally and has no hosted service. Supported releases are the latest published preview version.

Report a suspected vulnerability through this repository's **Security** tab using **Report a vulnerability**. Do not include exploit details, credentials, customer information, or sensitive files in a public issue. If private reporting is unavailable, open a public issue asking maintainers to enable a private channel without disclosing the vulnerability.

The maintainers will acknowledge a private report, investigate the impact, and publish a fix and disclosure when appropriate. There is no guaranteed response time for this volunteer preview.

Keep real bank data and credentials out of this repository. The local approval fields do not authenticate reviewers, and the evidence export is not a signed audit archive.
