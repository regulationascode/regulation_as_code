# Adoption

This workspace is a starting point for a bounded, human reviewed evaluation. It is not ready to run institution reporting.

## Suggested path

1. Choose one narrow public obligation and document why it is in scope.
2. Confirm the source version, effective date, applicability, reporting location, and interpretation with accountable legal and reporting reviewers.
3. Compare the synthetic timing scenario with the actual obligation facts, calendar, and technical specification.
4. Define synthetic valid, invalid, missing, boundary, and excluded cases.
5. Keep institution data and mappings in systems the institution controls.
6. Add identity, access, approval, retention, monitoring, release, recovery, and filing controls before considering operational use.
7. Measure a bounded pilot with comparable work items, defined time windows, role hours, rework, and evidence completeness.

## Measure carefully

Pilot Economics separates editable assumptions from entered baseline and pilot observations. Differences are descriptive. They do not establish causation or guarantee savings. Define inclusion rules, start and end events, and role hour capture before comparing periods. Investigate case mix and other changes before drawing conclusions.

The institution remains accountable for interpretation, implementation, data handling, controls, and decisions to operate. Read the [fork and privacy guide](fork_guide.md) before using private data or creating an institutional copy.
