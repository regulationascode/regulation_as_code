# Security policy

This public package is a synthetic demonstration. Do not place real financial data, credentials, customer information, institution-specific mappings, or approval evidence in issues, pull requests, tests, or public forks.

Report security concerns through the repository owner's private vulnerability-reporting channel, if enabled. Do not include sensitive data in a public issue.

The included CI workflow is read-only and uses no secrets or deployment permissions. Repository owners should review allowed Actions, pin Actions to reviewed commit SHAs where required by policy, protect the default branch, and review dependency updates.
